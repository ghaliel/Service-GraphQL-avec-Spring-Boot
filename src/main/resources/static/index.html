Exemples de requêtes

1. Récupérer tous les comptes

query { allComptes { id solde dateCreation type } }

2. Récupérer un compte par ID

query { compteById(id: 1) { id solde dateCreation type } }

3. Obtenir les statistiques

query { totalSolde { count sum average } }

4. Créer un nouveau compte (Mutation)

mutation { saveCompte(compte: { solde: 2500.0, dateCreation: "2024-12-01", type: EPARGNE }) { id solde type } }
